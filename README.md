# Instagram Image Gallery

Frontend-only Instagram Image Gallery for **@pavley_mousa**.

## Workflow

This is a manual gallery. There is no Instagram feed, no automatic synchronization, no backend, and no database.

Add each Instagram post individually from its post URL. The gallery saves the entries in the browser with localStorage.

## Add posts

Open **Manage Gallery**, paste an individual Instagram post URL, and save it. An image URL is optional when the Instagram post URL is provided.

## Features

- Individual Instagram post embeds
- Image URLs and local image uploads
- Lightbox and navigation
- Search and filters
- Newest/oldest sorting
- Arabic/English UI
- Dark/light/system theme
- Custom branding
- Add/edit/delete
- localStorage
- No automatic feed updates
